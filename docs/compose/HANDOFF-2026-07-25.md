## 已知坑

1. **Compose 跟滚**：`animateScrollToItem(index)` 默认顶对齐；长气泡会「闪顶」——已用 bottom offset；流式要动画但不要先 scrollOffset=0。
2. **底部判定**：必须结合 `canScrollForward`（有 contentPadding）。
3. **programmaticScroll**：程序滚动期间勿把内容增高误判为用户上滑 unpin。
4. **图片**：Maven 拉 Coil 曾 TLS 失败；现用 OkHttp+BitmapFactory。
5. **Release 签名**：无 `keystore.properties` 时 `assembleRelease` 用 debug 证书，不可分发。
6. **自动化 UI**：易误触系统相机；CJK `adb input text` 不可靠。
7. **闪退样例会话标题**：`吧唧图片`（`![…](/mnt/user-data/outputs/badge-bajie.png)`）— 图 null title 已修。
